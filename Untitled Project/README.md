# VSL — iOS Fitness & Productivity

A native iOS app developed in **Xcode** with **Swift, SwiftUI, and HealthKit**, combining workout analytics, health tracking, sleep insights, and productivity tools in a minimalist interface.

## Features
- **Focus:** Pomodoro timer, date-based tasks, and monthly calendar
- **Performance:** Apple Health workouts, activity-aware metrics, interval analysis
- **Health:** Weight, nutrition, and medication views
- **Sleep:** Latest recorded night and historical averages

## Technology
Swift · SwiftUI · Xcode · HealthKit · Local persistence

## Setup
These are Swift source files, **not a standalone Xcode project**. Add/replace the corresponding files in your existing VSL Xcode project, which must have the appropriate HealthKit capability and signing configuration. Then build and run on a supported iPhone.

## Privacy
Health information is read from Apple Health with user permission. Do not commit screenshots containing private health data, credentials, provisioning profiles, or local user data.

## Status
